# Анализ вакансий IT-специалистов с HeadHunter(идёт работа)

Проект для сбора, обработки и первичного анализа вакансий с платформы HeadHunter (HH.ru) с использованием Python и официального API.

## О проекте

Проект создан для практического изучения Python, работы с REST API и анализа данных.

Основная задача — получить данные о вакансиях в IT-сфере, структурировать их и исследовать рынок труда по различным параметрам: зарплатам, регионам, требованиям к опыту работы и другим характеристикам.

## Реализованный функционал

- Получение вакансий через API HeadHunter.
- Поиск вакансий по ключевым словам и регионам.
- Сбор данных с нескольких страниц API.
- Сохранение полученных данных в форматах JSON и CSV.
- Преобразование вложенных JSON-структур в Pandas DataFrame.
- Изучение структуры датасета и выявление пропущенных значений.
- Первичный статистический анализ вакансий.

## Используемые технологии

- **Python** — основной язык программирования.
- **Requests** — отправка HTTP-запросов и взаимодействие с API.
- **Pandas** — обработка и анализ данных.
- **Jupyter Notebook** — интерактивная работа с данными.
- **JSON / CSV** — форматы хранения данных.

## Источник данных

Для получения информации используется официальный API HeadHunter:

https://api.hh.ru/

Датасет содержит информацию о вакансиях, в том числе:

- Название должности.
- Работодатель.
- Информация о заработной плате.
- Регион размещения вакансии.
- Требуемый опыт работы.
- Тип занятости и другие характеристики.

Данные представляют собой снимок вакансий на момент сбора и могут не отражать текущее состояние рынка труда.

## Планы по развитию

- Улучшение очистки и предварительной обработки данных.
- Анализ распределения зарплат по IT-специальностям.
- Сравнение требований к специалистам с разным опытом работы.
- Исследование региональных различий на IT-рынке труда.
- Добавление визуализации результатов.
- Создание интерактивного дашборда.



Проект является частью самостоятельного изучения Python, анализа данных и программирования.
